# 🎭 Emoti - Emotion Detection using NLP

An NLP-based emotion detection application that predicts the emotion expressed in a given text.

## 🚀 Features

- Text-based emotion detection
- TF-IDF text vectorization
- Logistic Regression classification
- Confidence scores for predictions
- Probability distribution across emotions
- Interactive Streamlit interface

## 🧠 Machine Learning

The project uses:

- Python
- NLTK
- TF-IDF Vectorization
- Logistic Regression
- Streamlit

The model was trained on a dataset containing 16,000 text samples and 6 emotion classes.

## 📊 Model Performance

Test Accuracy: **86.28%**

## 🎭 Supported Emotions

- Sadness
- Anger
- Love
- Surprise
- Fear
- Joy
